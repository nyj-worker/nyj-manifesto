# 민선9기 공약사업 통합관리 시스템 (남양주시 예시 데모)

본 시스템은 지자체의 부서별로 분산된 공약사업을 하나의 일원화된 체계로 취합·검토·승인하고, 최종 승인된 안전한 자료만을 시민에게 지도와 쉬운말(6하원칙)로 투명하게 공개하는 **풀스택 웹 애플리케이션**입니다.

첨부된 **「(교통국) 민선9기 공약과제 실천계획.pdf」**의 실제 행정 서식(기본정보, 재원투자계획 표, 쟁점사항 및 해소방안, 연도별 추진계획, 일자별 추진실적 히스토리 등)을 100% 정밀하게 재현하여 샘플 데이터 및 기능으로 탑재하였습니다.

---

## 🌟 핵심 특징 및 주요 가치

1. **엄격한 4단계 책임행정 워크플로우:**
   - `담당 부서 실적입력/임시저장` ➔ `국 관리자 검토/반려` ➔ `정책팀 총괄 최종승인` ➔ `공개자료 관리(확정)` ➔ `시민 포털 공식 게시`
   - 반려 시 사유 입력 필수 및 재제출 이력 영구 보존
   - 검토 대기 중인 자료의 임의 수정 방지 및 승인 후 정정 시 신규 버전 생성
2. **공개 데이터와 내부 행정 데이터의 원천 격리:**
   - 시민 포털은 내부 API나 민감정보(공무원 내선번호, 내부 메모, 심사의견, 반려사유 등)를 일체 받지 않으며, 오직 `public_projects` 테이블 및 전용 API(`/api/public/*`)만 조회합니다.
3. **시민 중심 3대 지표 분리 공개:**
   - **완료 공약 비율(%)** vs **성과목표 달성률(%)** vs **예산 집행률(%)**을 엄격히 구분하여 표시
4. **생활밀착형 공약 지도 및 반경 검색:**
   - Leaflet 기반 인터랙티브 지도 (행정동 필터, 반경 500m~5km 검색, 현 위치 연동)
   - 시 전체 사업이나 좌표가 없는 사업을 임의 위치에 찍지 않고 **별도 목록 탭으로 분리**하여 제공
5. **공개 데이터 기반 6하원칙 쉬운말 AI 안내:**
   - 어려운 행정 용어를 시민 눈높이에 맞추어 6하원칙으로 자동 해설
   - 시민 관심사(지역, 교통, 복지, 스쿨존 등)에 맞춘 자연어 질의응답
6. **12대 필수 검증 시나리오 100% 자동화 테스트 통과**

## 🛠️ 기술 스택 (Technology Stack)

- **Backend:** Node.js (v24), Express 4, TypeScript, `node:sqlite` (Node.js 내장 SQLite 엔진 - 외부 C++ 컴파일 도구 없이 100% 무결점 영속화 보장)
- **Frontend:** React 18, TypeScript, Vite 6, Tailwind CSS v4, Lucide Icons, Leaflet
- **Testing:** tsx 기반 12대 필수 시나리오 자동 검증 스크립트 (`npm test`)

## 🚀 설치 및 로컬 실행 방법

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 및 통합 서버 실행
```bash
# 단일 포트(http://localhost:3001)에서 백엔드 API와 프론트엔드가 동시에 실행됩니다.
npx tsx server/index.ts
```
*(또는 Vite HMR 개발 서버 사용 시 `npm run dev`)*

### 3. 접속 주소
브라우저에서 **`http://localhost:3001`** 에 접속합니다.

## 👥 데모 계정 및 역할별 이용 방법

화면 최상단에 **[시연 모드 역할 빠른 전환 바]**가 항상 노출되어 있어 클릭 한 번으로 모든 직급의 권한을 즉시 체험할 수 있습니다.

| 역할 | 이름 / 소속 | 주요 권한 및 시나리오 |
|---|---|---|
| **일반 시민** | 남양주시민 | 로그인 불필요, 3대 지표 요약, 우리 동네 지도, 공약 검색, 쉬운말 AI 안내 |
| **부서별 담당자** | 양윤호 (교통정책과) | 소관 철도·스쿨존 공약(4-01 등) 실적 입력, 임시저장, 국 검토 요청 제출 (*타 부서 사업 수정 차단됨*) |
| **부서별 담당자** | 손승재 (대중교통과) | 똑버스 DRT, G-Pass 무상교통 실적 관리 |
| **부서별 담당자** | 이명후 (도로건설과) | 수석대교, 도로확장 실적 관리 |
| **국별 관리자** | 박교통 (교통국장실) | 소관 교통국 산하 4개 과 공약 검토 승인 및 반려 (반려 사유 입력) |
| **정책팀 총괄** | 김정책 (정책기획과) | 전 부서 공약 최종 승인, 공개자료 확정 및 시민 포털 공식 게시/철회 제어 |
| **시스템 관리자** | 최관리 (정보통신과) | 시스템 전체 감사 로그 조회, 사용자 권한 및 데이터베이스 관리 |

## 🔒 데이터베이스 구조 및 분리 체계

로컬 `data/promise_system.db`에 안전하게 SQLite 파일로 저장됩니다:

1. `users`: 데모 사용자 및 조직 정보
2. `projects`: 공약사업 기본정보, 재원투자표, 쟁점사항, 연도별 추진계획, 추진실적 히스토리 전체
3. `approval_history`: 단계별 승인/반려/게시 이력 및 반려 사유
4. `public_projects`: **시민 공개 전용 격리 테이블** (공식 승인·확정된 데이터만 복사되어 저장되며, 민감정보 원천 배제)
5. `audit_logs`: 모든 상태 변경 및 수정에 대한 영구 감사 로그

## 🏢 실제 기관 운영 배포 전 확인사항

1. **지자체 행정 전산망 SSO 인증 연동:** 현재 데모용 역할 스위처를 기관 온프레미스 SSO(GPKI / 행정전자서명)와 연계
2. **기관 GIS 서버 연동:** 브라우저 기본 OSM 타일 대신 지자체 내부 공간정보(GIS) 시스템 연계 가능
3. **외부 LLM API 키 설정:** 기관용 폐쇄망 AI 또는 상용 Gemini/OpenAI API 키를 환경변수로 주입하여 실시간 쉬운말 질의응답 고도화
